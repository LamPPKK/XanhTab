# XanhTab Gate X0 Hardware Report — 2026-08-18

## Kết luận

**NO-GO.** Môi trường Raspberry Pi Zero 2 W hiện tại chưa đủ điều kiện chạy bài benchmark Gate X0. Ba điều kiện bắt buộc đầu tiên đều chưa đạt:

1. `wpesrc` chưa được cài đặt.
2. `webrtcsink` không có trong các repository APT hiện tại.
3. Bộ mã hóa H.264 phần cứng thất bại ngay ở profile tối thiểu phát hành 720p15.

Vì 720p15 không khởi động được, bài thử 1080p30 và soak test hai giờ cho từng profile không được chạy. Kết quả này không chứng minh rằng phần cứng không thể đạt Gate X0; nó chỉ bác bỏ trạng thái sẵn sàng của image và pipeline hiện tại.

## Phạm vi kiểm tra

Bài kiểm tra được thực hiện trực tiếp trên Pi qua LAN. Chỉ dùng lệnh đọc trạng thái và pipeline GStreamer tạm thời; không cài package, không sửa cấu hình hệ thống và không triển khai service XanhTab. Địa chỉ LAN và thông tin xác thực không được lưu trong repository.

| Hạng mục | Giá trị quan sát |
| --- | --- |
| Board | Raspberry Pi Zero 2 W Rev 1.0 |
| OS | Debian GNU/Linux 13 (Trixie), Raspberry Pi kernel |
| Kiến trúc | `aarch64`, 64-bit |
| Kernel | `6.18.34+rpt-rpi-v8` |
| RAM | 415 MiB tổng; 163 MiB `MemAvailable` tại lần đo nền đầu tiên |
| Nhiệt độ | Khoảng 47,2–48,3 °C |
| Throttling tức thời | `vcgencmd get_throttled=0x0` |
| Wi-Fi | Khoảng -56 dBm, TX bitrate 72,2 Mbit/s |
| GStreamer | 1.26.2 |
| Video encoder | `/dev/video11`, `bcm2835-codec-encode`, khai báo H.264 capture |
| GPU render node | `/dev/dri/renderD128` |
| Runtime storage | `/run` là `tmpfs` |

Các số liệu nhiệt độ, throttling và Wi-Fi ở trên chỉ là preflight snapshot, không phải kết quả soak test.

## Tái hiện lỗi encoder 720p15

Pipeline tối thiểu sau được chạy ba lần:

```sh
gst-launch-1.0 -q \
  videotestsrc num-buffers=300 is-live=true ! \
  video/x-raw,format=I420,width=1280,height=720,framerate=15/1 ! \
  v4l2h264enc ! h264parse ! fakesink sync=false
```

Cả ba lần đều dừng với mã thoát 1 sau khoảng 0,7–1,0 giây:

```text
Failed to process frame
Maybe be due to not enough memory or failing driver
streaming stopped, reason error (-5)
```

Kernel ghi nhận:

```text
bcm2835_codec_start_streaming: Failed enabling i/p port, ret -3
```

`CmaFree` trước các lần thử được quan sát ở nhiều mức, gồm khoảng 5,5 MiB, 25,4 MiB và 67,1 MiB. Encoder vẫn thất bại ở lần có khoảng 67,1 MiB CMA trống; do đó chưa đủ bằng chứng để quy nguyên nhân chỉ cho thiếu CMA. Cần chẩn đoán riêng tương thích driver/firmware, buffer negotiation và memory pressure.

## Trạng thái tiêu chí Gate X0

| Tiêu chí | Trạng thái | Ghi chú |
| --- | --- | --- |
| Đúng board, OS và kiến trúc | PASS | Pi Zero 2 W, Trixie, ARM64 |
| Có thiết bị encoder và render node | PASS | `/dev/video11`, `/dev/dri/renderD128` |
| Có `wpesrc` | FAIL | Chưa cài package WPE/GStreamer |
| Có `webrtcsink` | FAIL | Không có package trong repository hiện tại |
| Encode 720p15 tối thiểu | FAIL | Lỗi `bcm2835-codec` ở cả ba lần thử |
| Encode/stream 1080p30 | SKIPPED | Không chạy sau khi release floor thất bại |
| Frame drop dưới 2% | NOT RUN | Chưa có stream hoạt động |
| Input latency p95 dưới 250 ms | NOT RUN | Chưa có stream/control loop hoạt động |
| Browser + stream dưới 400 MiB | NOT RUN | Chưa triển khai process tree |
| Còn ít nhất 48 MiB `MemAvailable` | NOT RUN | Snapshot nền đạt, nhưng chưa đo dưới tải |
| Không OOM/throttle kéo dài | NOT RUN | Snapshot không throttle; chưa soak test |
| Hai giờ cho mỗi profile | NOT RUN | Bị chặn bởi dependency và encoder |

## Hành động tiếp theo

1. Cài `gstreamer1.0-wpe` và `libwpewebkit-2.0-1` từ repository Trixie được hỗ trợ, sau khi chụp lại trạng thái image.
2. Build và đóng gói `rswebrtc`/`webrtcsink` tương thích GStreamer 1.26.2 cho ARM64; đưa artifact vào signed release manifest thay vì giả định package APT tồn tại.
3. Chẩn đoán lỗi `bcm2835-codec` bằng pipeline tối thiểu trước khi thêm WPE, audio hoặc WebRTC.
4. Chỉ khi 720p15 encode ổn định mới ghép `wpesrc` → conversion → V4L2 H.264 → `webrtcsink` và kiểm tra control DataChannel.
5. Sau khi pipeline hoàn chỉnh hoạt động, chạy `scripts/x0-gate.sh` đủ hai giờ cho từng profile và đánh giá bằng `scripts/evaluate-x0.sh`.

Không tuyên bố Gate X0 đạt và không mở Gate X1/X2/X3 dựa trên lần kiểm tra này.
